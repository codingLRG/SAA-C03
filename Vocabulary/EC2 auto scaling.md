# Auto Scaling Group
- Organizes [[EC2]] instances into groups
- A logical unit for scaling
- Minimum, Maximum and Desired number target

# Config Template
- Types
	- Launch template (preferred)
	- Launch config (limited features)
- Template for:
	- Auto Scaling Group
	- [[AMI]] ID
	- [[EC2 Instance Type]],
	- Key Pair
	- [[Security Group]] 
	- Block device mapping

# Scaling option
- Scaling behavior
	- Dynamic
	- Predictive
	- Scheduled
