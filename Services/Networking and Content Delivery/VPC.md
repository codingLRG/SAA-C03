> Virtual Private Cloud

Logical private network with [[AWS]] cloud
Launch [[EC2]] instances and other services
Full customization:
- Create subnets
- IP Ranges
- Gateways
- Route tables
Internet gateway allows connection to public internet
Virtual private gateway allows connection to on-premises enterprise location, requires [[Outposts]]
Can connect to other VPC with feature called [[Peering]]
