Scalable, durable, secure, low-cost real-time data streaming service in ==real-time==
Gigs from thousands of different sources in miliseconds
- Real-time applications
- Website clickstreams
- Database Event Streams

Provides ==ordering of records==
- Data events must be received in ordered manner
- Process app, web, or mobile game in order of receipt

Similar with [[SQS]] except by default [[SQS]] does not preserve order and is not providing real-time, however [[SQS]] is more scalable and has the highest available throughput
