> Simple Storage Service

Object storage service
Durable and scalable
Virtually unlimited data
Files are called objects that you upload to a bucket
REST API calls

| Type                            | Use Case                                  | Lifecycle Policy           |
| ------------------------------- | ----------------------------------------- | -------------------------- |
| Standard                        | Frequent accessed                         |                            |
| Standard-IA (Infrequent Access) | Long-lived, less frequently accessed data | From Standard (30 Days)    |
| Intelligent-Tiering             | Unknown access patterns                   |                            |
| One Zone-IA                     | Long-lived, less frequently accessed data | From Int-Tiering (90 Days) |
| [[S3 Glacier]]                  | Low-cost long term storage                |                            |
| Glacier Deep Archive            | Low-cost long term storage                | From Glacier (180 Days)    |
[[ACL]]s to secure buckets and object

MFA and Versioning to prevent accidental data deletion
Cross Region Replication to replicate across regions
Transfer acceleration and Multipart Upload expedite data transfer
