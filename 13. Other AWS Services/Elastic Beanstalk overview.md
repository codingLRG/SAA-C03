[[Elastic Beanstalk]]
Reduces need for setting all of the following for a webapp:
- [[EC2]] 
- [[ALB|Application Load Balancer]]
- [[EC2 auto scaling]]
- Instance patching and updates

[[Platform as a Service]]
Optional [[RDS]] on setup, can connect to outside DB with proper security group and DB settings

[[X-ray]] for debugging
[[CloudWatch]] Logs for monitoring
[[SNS]] for notifications
