Event Notification for:
- New Object Creation
- Object Deletion
- Object Restoration from [[S3 Glacier]]
- [[Reduced Redundancy Storage]] object lost events
- Replication events

Can publish notifications to:
- [[SNS]]
- [[SQS]]
- [[Lambda]]

Transmitted within seconds and delivered at least once
Enable object versioning to ensure the event notification is sent whenever you upload an object
