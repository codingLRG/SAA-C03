[[DynamoDB Streams]]

| [[DynamoDB]] Item           | Purpose                                                                                                                                                                                                                                       |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Table                       | Collection of related data that can represent an object, idea, role or concept                                                                                                                                                                |
| Item                        | Row with [[DynamoDB TTL]], can have a nested attribute                                                                                                                                                                                        |
| Attribute                   | Column                                                                                                                                                                                                                                        |
| Primary Key / Partition Key | Uniquely identifies each item in table, giving search functionality. Used as internal hash function. Must be a [[Scalar]]. Can only be a string, num or binary. Can be either Simple (Just Partition Key) or Composite (Partition + Sort Key) |
| Secondary Index             | Makes queries faster by enabling advanced queries to access subsection, similar to Index                                                                                                                                                      |
| Global Secondary Index      | Different Partition and Sort Key from Primary Key                                                                                                                                                                                             |
| Local Secondary Index       | Same Partition Key but different Sort Key from Primary Key                                                                                                                                                                                    |
