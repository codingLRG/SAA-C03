[[Global Secondary Index]] and [[Local Secondary Index]]

| Type                            | Key Attributes                                | Span query                                    | Index operations           | Size restriction per partition key value | Read consistency    | Provisioned Throughput consuption                                         | Projected Attributes                                                    |
| ------------------------------- | --------------------------------------------- | --------------------------------------------- | -------------------------- | ---------------------------------------- | ------------------- | ------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| [[Global Secondary Index\|GSI]] | Partition Key + Sort Key + Non-key attributes | All data in base table, across all partitions | Anytime                    | No restriction                           | Eventual            | Own provisioned throughput for RW activities (W should be greater than R) | Only request attributes that are projected                              |
| [[Local Secondary Index\|LSI]]  | Sort Key + Non-key attributes                 | Scoped on partition key of its base table     | Only during table creation | Total size <= 10 GB                      | Eventual and strong | Consumes from base table                                                  | Non projected are fetched from base table by [[DynamoDB]] automatically |
